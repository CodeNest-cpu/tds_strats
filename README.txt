TDS Strats

Открыть: распаковать архив и открыть index.html. Шрифты подгружаются из интернета,
без него сайт работает на системных.

Шаги отмечаются кликом. Кнопка «Панель шагов» вверху включает нижнюю панель
с текущим шагом и кнопками «Готово» и «Назад». Вместе с ней работают клавиши:
  Пробел, Enter или →   отметить следующий шаг
  ←  или Backspace      снять последнюю отметку
По умолчанию панель выключена.
  RU / EN вверху переключает язык. Названия башен всегда на английском.

Карта и метки башен
  1. Положи скриншот карты в папку maps (например maps/honey-valley.jpg).
     Либо загрузи его прямо на сайте кнопкой «Загрузить скриншот», тогда он
     сохранится только в твоём браузере.
  2. Нажми «Расставить башни» над картой, выбери башню и кликай по карте.
     Метки можно двигать, двойной клик удаляет.
  3. Кнопка «Скопировать JSON» даёт готовый список. Вставь его в поле markers
     в strats.js, и метки будут у всех, кто открывает сайт.
  Метка текущего шага подсвечена, башни, которые ещё не поставлены, полупрозрачные.

Новая стратегия: открой strats.js, скопируй объект внутри STRATEGIES и поменяй поля.
  id         уникальное имя латиницей, попадает в ссылку (#frost-honey-valley)
  team       solo, duo, trio или squad
  mode, map  режим и карта
  modifiers  список модификаторов
  loadout    башни в лодауте
  mapImage   путь к картинке карты
  markers    метки башен (см. выше)
  build      итоговая расстановка: башня, количество, до чего качать
  waves      сколько волн в режиме
  timeline   отметки на шкале волн: диапазон (from, to) или одна волна (at)
  notes      заметки: tag, tone (ice, warn, mute), text
  steps      шаги. Каждый текст парой { en, ru }. Если у шага есть условие по волне,
             добавь sub: [ ... ]

Подсвечиваются сами: Engineer, Enforcer, Hacker, Juggernaut, DJ, "lvl 3" / "лвл 3",
"wave 20" / "волна 20", red / purple track, max. Новую башню добавь в TOWERS в app.js
и цвет в style.css.

Прогресс, язык, тема и свои метки хранятся в браузере (localStorage).
